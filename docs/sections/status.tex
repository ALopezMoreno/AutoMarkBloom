\noindent The bud stage is being reworked so that it can produce the swollen,
crumpled ``marshmallow'' buds and complex packing of real peonies
(\cref{sec:packing-limits}). The sections on shells, the automaton, sheets and
packing describe the code as it stands today and will be revised when that
rework lands.
